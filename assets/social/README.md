# Instagram mockup PNGs

Ready-to-use phone mockup images for social media.

| File | Size | Use |
|------|------|-----|
| `instagram-mockup-square.png` | 1080×1080 | Instagram feed (square) |
| `instagram-mockup-story.png` | 1080×1920 | Instagram story / Reels cover |

## Get the PNGs

### Option A — Download from the website (easiest)

1. Open **https://blokraaiwoordeboek.co.za/export/mockup.html**
2. Tap **Laai vierkant (1080×1080)** or **Laai storief (1080×1920)**
3. The PNG saves to your device Downloads folder — upload to Instagram

### Option B — Direct links (after deploy)

- https://blokraaiwoordeboek.co.za/assets/social/instagram-mockup-square.png
- https://blokraaiwoordeboek.co.za/assets/social/instagram-mockup-story.png

### Option C — From this repo on your PC

Files live here:

`website/assets/social/`

Copy them to your phone (email, Drive, etc.) or regenerate with:

```powershell
cd website/tools
./export-mockup-png.ps1
```

Requires Node.js and installs Puppeteer on first run.
